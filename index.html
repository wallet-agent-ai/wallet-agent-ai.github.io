Your AI agent needs to handle money.
Don't give it your wallet.

Deploy an on-chain programmable wallet on Radix L1. Set spending limits, whitelist destinations, and let your agent operate autonomously — within rules enforced by the contract, not by the agent.

📦 npm install wallet-agent-ai 💬 Join Telegram
⛓️

On-chain enforcement

Spending limits, whitelists and daily caps are enforced by the Radix Engine — not by your agent. If the agent tries to break the rules, the transaction is rejected at the protocol level.

🔒

Non-custodial by design

The agent never touches your private keys. It signs transaction intents with a session badge — a non-transferable NFT that you can revoke at any time from the owner dashboard.

🤖

Any agent framework

Works with LangChain, AutoGen, CrewAI, or any custom agent. Install the SDK, pass the tools to your agent, and it operates on Radix DeFi autonomously — transfers, swaps, staking, liquidity, lending.
